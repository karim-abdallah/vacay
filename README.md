# build move files  
for linux  
`rm -rf ../frontend/static && mv -f build/static ../frontend/ && mv -f build/* ../frontend/templates/frontend/`  
for window  
`rd /s /q ..\frontend\static && move /y build\static ..\frontend\ && move /y build\* ..\frontend\templates\frontend\`
